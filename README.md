A one-line roast of a smart fridge that refuses to open after midnight, entered in make.fun's "Midnight Fridge Roast" bounty. The program writes exactly one line to `entry.txt`:

> Guarding cold pizza like it's the crown jewels? It's 12:01, not a bank heist — you're a fridge, not a vault.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the entry line to `entry.txt` inside the output directory (`/output` by default).
